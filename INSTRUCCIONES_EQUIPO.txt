2. HOJA DE RUTA Y TAREAS PARA CADA INTEGRANTE
--------------------------------------------------------------------------------

--------------------------------------------------
[DEV 2: MOTOR MATEMÁTICO & OR-TOOLS (BACKEND)]
--------------------------------------------------
Tu objetivo: Programar el Agente Baseline y el Agente Inteligente (OR-Tools) en 'Backend/Backend_Dev2/'.

Pasos:
1. Navega a 'Backend/Backend_Dev2/'.
2. Consulta las órdenes disponibles en Tiger Data (tabla 'orders' donde status = 'PENDIENTE').
3. Para reutilizar las funciones de ruteo e importar de 'Backend/Backend_Dev1/environment.py':
   ```python
   import sys, os
   sys.path.append(os.path.abspath("../Backend_Dev1"))
   from environment import load_or_create_graph, calculate_route_distance
   
   G = load_or_create_graph() # Carga el mapa de Monterrey en ~3 segundos
   distancia_m = calculate_route_distance(G, node_origen, node_destino)
   ```
4. Aplica el algoritmo de batching (agrupación de pedidos por cercanía).
5. Al aceptar o entregar ordenes:
   - Actualiza el status en la tabla 'orders' ('ACEPTADA', 'COMPLETADA').
   - Registra posiciones en 'driver_logs'.
   - Inserta la ganancia neta ($ MXN) en 'transactions'.

--------------------------------------------------
[DEV 3: EXPLICABILIDAD & GEMINI API (BACKEND)]
--------------------------------------------------
Tu objetivo: Intercepta las decisiones de OR-Tools y redacta justificaciones en lenguaje natural usando Gemini API.

Pasos:
1. Configura tu GEMINI_API_KEY en el archivo '.env'.
2. Crea un script en tu módulo que reciba las acciones de Dev 2 (ej. "Orden #4 rechazada por tráfico en Av. Constitución").
3. Envia el contexto geográfico y evento (Lluvia Intensa / Bloqueo Vial) a Gemini 1.5 Flash.
4. Retorna el texto para que Dev 4 lo muestre en la interfaz de Streamlit.

--------------------------------------------------
[DEV 4: INTERFAZ STREAMLIT & DESPLIEGUE EN VULTR (FRONTEND & DEPLOY)]
--------------------------------------------------
Tu objetivo: Construir el dashboard interactivo en Streamlit + Folium y desplegar en Vultr.

Pasos en Frontend (Streamlit):
1. Construir la UI en Streamlit consumiendo Tiger Data:
   - Mapa en vivo: Lee posiciones desde 'driver_logs' y pedidos desde 'orders'.
   - Métricas financieras: Muestra contadores en $ MXN desde 'transactions' (Baseline vs Smart).
   - Panel de Explicabilidad: Muestra los textos de Gemini API (Dev 3).
   - Botón de Eventos Disruptores: Inyectar "Lluvia Intensa" o "Bloqueo Vial".

Pasos para el Despliegue en Vultr (VPS Cloud):
1. Crear una VPS en Vultr (Ubuntu 22.04 LTS o 24.04 LTS).
2. Conectarte por SSH: `ssh root@<IP_DE_VULTR>`
3. Instalar dependencias:
   sudo apt update && sudo apt install -y python3-pip python3-venv git
4. Clonar el repositorio:
   git clone https://github.com/Ariel-Hdz-Gar/HackMTY-Infosys-2026-Project--Gig-Economy-Courier-agent-Monterrey-.git
   cd HackMTY-Infosys-2026-Project--Gig-Economy-Courier-agent-Monterrey-
5. Instalar entorno virtual y dependencias:
   python3 -m venv venv
   source venv/bin/activate
   pip install -r Backend/Backend_Dev1/requirements.txt
6. Copiar variables de entorno:
   nano .env (Pegar DATABASE_URL de Tiger Data)
7. Correr la app de Streamlit en el puerto 8501:
   nohup streamlit run app.py --server.port 8501 --server.address 0.0.0.0 &
